# WebOS-DuckDuckGo-Shortcut-for-LG-TV

DuckDuckGo WebOS App

A lightweight shortcut to open DuckDuckGo on your LG WebOS TV.

How to Use

Download the prebuilt .ipk file from this repository.

Enable Developer Mode on your TV and connect it via webOS CLI.

Install the app using:

ares-install --device <your-device> com.duckduckgo.web_1.0.0_all.ipk
